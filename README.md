# StarryOS Terminal Simulator

A browser-based simulated Linux-like operating system built with HTML, CSS, and JavaScript.

 🚀 Features
- Virtual file system (create, delete, edit files & folders)
- Terminal supporting Linux-like commands
- Vim & Nano-style text editors (insert/normal modes)
- Process manager simulation (ps, top, kill)
- Networking commands simulation (ping, curl, wget, ssh)
- Pipes support: ls | grep, cat | wc, etc.
- File explorer UI synced with terminal
- Memory & system monitoring panels

 📂 Supported Commands
ls, cd, pwd, mkdir, touch, rm, cp, mv, cat, grep, find, nano, vim, ps, kill, top, df, du, free, ping, curl, wget, sudo, apt, history, man, help, and more.

 🧠 Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (No frameworks)

 🎯 Purpose
This project simulates a Linux terminal environment inside the browser for educational and practice purposes, helping understand file systems, CLI commands, and OS behavior.
